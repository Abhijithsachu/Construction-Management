# 🏗️ Construction Management System

A full-stack Construction Management System built using the MERN stack. This application helps manage construction projects, track progress, handle resources, and streamline communication between users and administrators.

---

## 🚀 Features

* 👤 User Authentication (Login / Register)
* 🏗️ Project Management
* 📊 Project Progress Tracking
* 📁 Resource Management
* 📩 WhatsApp Order/Request Integration *(optional upgrade)*
* 🧑‍💼 Admin Dashboard *(planned upgrade)*

---

## 🛠️ Tech Stack

**Frontend**

* React.js
* Tailwind CSS (or CSS)

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB

---

## 📂 Project Structure

/frontend → React frontend
/backend → Node.js backend
/routes → API routes
/controllers → Business logic
/models → MongoDB schemas

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Abhijithsachu/Construction-Management.git
cd Construction-Management
```

### 2. Install dependencies

```bash
# Backend
cd backend
npm install

# Frontend
cd frontend
npm install
```

### 3. Setup environment variables

Create a `.env` file in the server folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```

---

### 4. Run the project

```bash
# Start backend
cd backend
nodemon index.js

# Start frontend
cd frontend
npm run dev
```
